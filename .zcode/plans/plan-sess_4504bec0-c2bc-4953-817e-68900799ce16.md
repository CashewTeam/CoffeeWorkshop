# Phase 1 资源修复 PR（仅资源，不碰 Java）

## 目标
在不修改任何 Java 代码的前提下，修复所有 P0 级资源问题：缺失/不规范的贴图路径、`.lang` 旧式语言文件、`forge_marker` 残留、`coffeeworkshop` 命名空间污染、`mods.toml` 占位 URL。完成后玩家应能在客户端和资源加载阶段不再看到紫色方块和缺失翻译；blockstate、模型、命名空间全部统一到 `coffeework`，并符合 1.20.1 现代规范。

## 范围（本 PR）
仅资源改动。  
不在本 PR：机器 `use(...)` 与 LIT 重构、tick bug 修复、配方系统、Loot/Tags、POI 全状态、客户端隔离。
所有改动提交到当前 `1.20.1` 分支，不另开分支。

## 精确改动清单

### 1. `src/main/resources/META-INF/mods.toml` 占位 URL（M-01）
- 把 `issueTrackerUrl="https://github.com/your-repo/coffeework/issues"` 改为 `https://github.com/CashewTeam/CoffeeWorkshop/issues`（与 `git remote` 一致）。
- 删除整个 `updateJSONURL="https://example.com/coffeework/update.json"` 行（Forge Update Checker 不接受假地址，留着会触发协议错误；该字段本来就是可选）。在末尾提交说明里注明。

### 2. 三个 `.lang` → `.json`（R-01）
- 新增：
  - `assets/coffeework/lang/en_us.json`
  - `assets/coffeework/lang/zh_cn.json`
  - `assets/coffeework/lang/ja_jp.json`
- 转换规则：
  - 跳过空行与 `#` 开头注释；
  - 每行 `key=value` → JSON 字符串键值对；
  - 重复键（zh_cn 19 个、ja_jp 20 个、en_us 0 个）保留**最后一次**出现（与 Forge `LangMigrator` 行为一致）；
  - 同步做命名空间修复：`effect.coffeeworkshop.*` 和 `entity.minecraft.villager.coffeeworkshop.*` 全部改 `coffeework`（en_us 共 6 项）；
  - 用户选择"机械转换、保留原值"，所以翻译值不动；43 个"registry-name 即英文值"的项保持原样（不替换），符合工作流要求；
  - UTF-8 无 BOM，2 空格缩进；
- **不**删除原 `.lang` 文件（本 PR 不删，留给后续 PR/产物验证后再清理，避免一次性改动过大）。

### 3. Blockstate 模型路径批量修复（R-02 + R-04）
- 全部 126 个 `assets/coffeework/blockstates/*.json` 中共 610 处 `"model": "coffeework:<name>"` 改写为 `"model": "coffeework:block/<name>"`。
- 仅 `coldbrew_pot.json` 含 `forge_marker` 与 `defaults`：移除这两个键，把 `defaults` 里的 model 同样加上 `block/` 前缀；`ferm=0..8` 各状态保留。本步不做 FER 属性 Java 端修复（Phase 4 范围）。

### 4. 模型中原版贴图名迁移（R-03）
仅处理**裸** `blocks/<old_name>` 形式的引用（共 ~205 处），不影响 `coffeework:blocks/...`（这些是本 mod 自有路径，正常）。

执行：通过一个 Python 脚本读取每个目标模型 JSON，按"原始字符串值"精确替换（不会误改 parent 或 layer），改写后再格式化输出 JSON。

### 5. 验证脚本
新增 `tools/audit_resources.py`（纯 stdlib Python）：
- 校验所有生成的 JSON 文件能 `json.loads` 通过；
- 校验 0 个 `forge_marker` / 0 个 `defaults`；
- 校验 0 处裸 `coffeework:<model>` 引用（必须都是 `coffeework:block/<model>`）；
- 校验所有 `block/<model>` 目标文件存在；
- 校验 0 处裸 `blocks/...` 原版贴图（除 `anvil_base` 22 文件豁免并被列入报告）；
- 校验 0 处 `coffeeworkshop` 命名空间 key；
- 输出 `build/reports/resource-audit.md` 简报，列出剩余 22 个 `anvil_base` 待人工挑选的文件路径。
